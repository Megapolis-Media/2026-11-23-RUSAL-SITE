# Новогодний экспресс РУСАЛ FM

Одностраничный сайт праздничного телерадиоэфира 23 декабря 2026 года с 08:00 до 12:00 по Москве. Клиент написан на HTML, CSS и JavaScript. Сервер работает как Cloudflare Worker, данные хранятся в D1. Локальная разработка использует SQLite и тот же обработчик запросов.

## Запуск

Требуется Node.js 22.13 или новее. Устанавливать пакеты не нужно.

```bash
cp .env.example .env
node --env-file=.env scripts/dev.mjs
npm run build
```

Сайт открывается на http://localhost:3000. Сборка создаёт `dist/server/index.js`. SQL-схема находится в `drizzle/0000_initial.sql`. Развёртывание требует привязки D1 с именем `DB` и выполнения миграции. Локальная база создаётся в `.data/local.sqlite`.

## Настройки сервера

| Переменная | Назначение |
|---|---|
| `FACECAST_EMBED_URL` или `FACECAST_EMBED_CODE` | Штатный iframe Facecast для прямого эфира |
| `FACECAST_RECORDING_URL` или `FACECAST_RECORDING_EMBED_CODE` | Штатный iframe Facecast для записи |
| `CHAT_CONSENT_TEXT`, `CHAT_CONSENT_VERSION`, `CHAT_POLICY_URL` | Утверждённый текст, версия согласия и HTTPS-ссылка на политику. Без этих значений форма чата закрыта |
| `CHAT_ENABLED` | `false` закрывает отправку независимо от панели |
| `ADMIN_TOKEN` | Длинный случайный ключ для входа на `/admin`. Хранить как секрет |
| `RATE_SALT` | Отдельный случайный секрет для хеширования ключей ограничения частоты |
| `MUSIC_ENABLED`, `MUSIC_CLOSE_AT` | Закрытие заявок. Для даты используйте ISO 8601 с явным смещением |
| `RADIO_STREAM_URL` | При необходимости заменяет радиопоток из ТЗ |
| `BROADCAST_PHASE` | Начальный режим `auto`, `before`, `live` или `replay`. Сохранённое в панели значение имеет приоритет |

В `/admin` организатор может выгрузить заявки в CSV с московским временем, удалять сообщения вместе с фотографиями, закрывать чат и переключать режим эфира. Фотографии хранятся вместе с сообщениями в D1 и удаляются одной транзакцией. Срок хранения определяет организатор перед открытием чата.

## Принятые решения

- Дедлайн видеопоздравлений взят из раздела 8.3 и приёмочного сценария. Кнопка скрывается в 00:00 23 декабря по Москве. Анонс остаётся до 12:00.
- Для двух композиций из Figma использованы доступные растровые превью. Загрузка исходных слоёв ограничена доступом к экспорту. Логотипы РУСАЛ и РУСАЛ FM получены из Dropbox заказчика. Логотип «Мегаполис Медиа» используется в подвале сайта.
- Временная приватная публикация предназначена для проверки. Подключение `fm.rusal.ru` требует доступа к DNS и согласования рабочего размещения. Для запуска нужны реквизиты Facecast, утверждённые юридические материалы и доступ организатора.
